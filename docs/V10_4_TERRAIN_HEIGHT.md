# V10.4 — плавнее спуск и подъём по рельефу

## Зачем

На реальной карте CF Map 3.0 путь может проходить через ступени и небольшие
перепады высоты. В V10.3 широкой ходьбе требовалась твёрдая опора не глубже
~1 блока под следующей позицией, а резервный A* не выпускал соседние точки
ниже на два блока. Перед уступами некоторые юниты останавливались и подёргивались,
хотя нормальное падение должно происходить естественно под действием гравитации.

## Что изменено

- В `CFWideMarch.safeStep` опора ищется до **двух блоков ниже** текущих ног.
  Проверяется реальное столкновение с полом, сухость, свободное пространство
  и принадлежность приземления своей дорожке.
- `CFGroundGenerator`, `CFLaneRuntimeGenerator` и `CFLaneSearch.Bounded` допускают
  переход вниз на **до 2 блоков**, вверх — **до 1 блока за шаг**. Подъём на
  два блока остаётся возможным через лестницу/ступени и несколько шагов,
  но не прыжком сквозь вертикальную стену.
- `CFWideLaneGeometry` мягче учитывает отклонение ступней от высоты маршрута:
  `2.25` блока вместо `2.0`. Это **не расширение полосы по X/Z**, не
  переключение лайна и не разрешение полёта.
- Пока моб уже находится в воздухе, краткая задержка по X/Z не считается
  новой блокировкой и не запускает лишний поиск пути.
- При реальном спуске **нет принудительного переноса Y**: вертикальное
  движение и гравитация по-прежнему контролируются Minestom. Существующая
  обработка полублоков, столкновений и физического выталкивания юнитов сохранена.
- Все параметры локальны для движения; правила разметки Map 3.0,
  компиляция керамических замков и кеш маршрутов не изменены.

## Тесты

Новый `CFVerticalTravelSelfTest` добавлен в штатный `server/build.sh`.
Он проверяет реальную Minestom-физику столкновений на искусственном уступе,
переходы A* вниз на два блока, подъём на один блок, запрет глубокого обрыва,
двухблочной стены и воды. Тест не открывает пользовательский мир.

После сборки на Fedora / Java 25 проверить в игровом матче:

1. Спуск на 1 блок и на 2 блока (с настоящим полом внизу) без дёрганья.
2. Подъём по плитам / ступеням и через один полноценный блок обычным прыжком.
3. Глубокая яма и вода остаются запрещёнными обходами; через стены не проходят.
4. Обе команды проходят маршрут в свои стороны, не меняя laneId.
5. Ни один `.mca` не перезаписывается; `G`, короли, урон, башни работают как раньше.

Не путать прохождение Java-тестов с настоящим проверенным матчем.
