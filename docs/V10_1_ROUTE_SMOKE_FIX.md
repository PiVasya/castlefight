# Castle Fight V10.1: проверка маршрутного компилятора без внешней карты

`bash build.sh server` запускает `CF23FourLaneRouteSmoke` на полностью
синтетическом мире, который создается самим тестом в RAM. Пользовательский
мир Minecraft и папка `maps/` при этом не нужны.

V10 мог остановить сборку сообщением `Incomplete path (not certified)` на
свободном плоском соединении между центром керамического трона и маяком.
Причина практической ошибки: нативный эвристический поиск может вернуть
`BEST_EFFORT` на участке, который физически проходим.

Исправление: `CFLaneSearch.find` вначале пробует строго проверенный прямой
маршрут ТОЛЬКО для плоских отрезков. Каждые 0.25 блока проверяются:
- допустимость точки по коридору;
- твердая опора и свободное место для коллизии;
- отсутствие столкновения при переходе от предыдущей точки.

Если прямая блокирована или есть перепад высоты, как и раньше используется
полноценный `PathGenerator`; неполные пути по-прежнему отвергаются.
Синтетический интеграционный тест дополнен проверкой успешной прямой
и отказа при появлении препятствия. Никакие self-tests не отключены.

После распаковки в корень Git-проекта (не затрагивать `.git`):

    bash build.sh server

При успехе в конце выводится `[CF BUILD] SUCCESS`, а готовый сервер
находится в `dist/CastleFight/`. Тест компиляции не использует карту автора.

В данной среде отсутствуют JDK 25 и Maven, поэтому полная проверка
этой правки должна быть выполнена на Fedora автора.
