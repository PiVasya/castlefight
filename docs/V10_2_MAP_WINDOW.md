# V10.2: квадрат 50 чанков от нулевого чанка

- `chunkX` и `chunkZ` от `-50` до `50` включительно, максимум 10 201 чанк.
- Загружаются только существующие чанки из этой области; чтение мира за
  границей отключено в `CFReadOnlyMapLoader`. Исходные `.mca` не удаляются.
- Компилятор маяков/строительных зон/замков остаётся общим, а
  `compiled-routes-v3.bin` по-прежнему содержит оба замка и пути.
- Целиком далёкие region-файлы не участвуют в проверке кеша.
- Проверка `CFMapWindowSelfTest` включена в сборку, старые тесты сохранены.

Обновление пользователя:

1. Распаковать полный архив в Git-папку `~/Рабочий стол/castlefight/` без
   затрагивания `.git`.
2. Из корня Git запустить `bash build.sh server`.
3. Заменить `core/` и `start.sh` в отдельной папке
   `~/Рабочий стол/CastleFight/` версиями из `dist/CastleFight/`.
4. Не копировать и не удалять `maps/` и `data/`.
5. Запустить `bash start.sh my-arena` из отдельной папки сервера.

Для карт возле границы проверь, что все девять блоков керамики замка и
ковровые площадки 3x3 целиком попадают в квадрат.
