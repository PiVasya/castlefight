# Castle Fight V10.5.4 — клиентские регрессионные тесты

## Причина

Gradle 9.7.1 успешно компилировал клиентский код, но прерывал сборку на
`:test` с сообщением `There are test sources present ... did not discover any tests`.
Все три текущих теста являются самостоятельными классами с `public static
void main(String[] args)`, не имеют аннотаций JUnit. Это ошибка **конфигурации
запуска тестов**, а не баг из мира пользователя или пропажа тестовых исходников.

## Исправление

В `client/build.gradle` определены три явные задачи JavaExec:

- `cfArrowMotionSelfTest` — сетевой формат и интерполяция стрел.
- `cfOverlayMeshSelfTest` — границы цветных строительных зон и отсечение невидимых частей.
- `cfOverlayWireClientSelfTest` — приём геометрии с сервера и сборка клиентской сетки.

Все задачи используют `sourceSets.test.runtimeClasspath`, зависят от
`testClasses`, запускаются на JDK 25, включают `-ea` и прерывают сборку при ошибке проверки или
ненулевом коде завершения Java.

Стандартная задача Gradle `test` **сохранена** и зависит от этих трёх
проверок. Лишь установлен `failOnNoDiscoveredTests=false`, потому что
проверки в этой версии не написаны в формате JUnit. Настоящие JUnit-тесты,
если будут добавлены в будущем, не отключаются.

Проверить можно командами в корне исходного Git-проекта:

```bash
bash build.sh client
# или
bash build.sh all
```

Скрипт запускает Gradle с `--continue`, чтобы при нескольких независимых
ошибках Gradle попытался показать их за один прогон (зависимые от упавшей
компиляции задачи всё равно не могут выполняться).

Полный лог должен включать выполнение всех трёх задач и строку
`[CF BUILD] CLIENT SUCCESS` при успехе. Это не подтверждает работу графики
Minecraft без отдельного запуска клиента.

## Проверки в среде подготовки

Автономно скомпилированы и выполнены **все три исходные self-test main** на
доступном JDK 21. Все три завершились успешно. Также проверены скрипты
Bash и идентичность трёх общих классов сетевого протокола. Java 25,
Gradle 9.7.1 и реальный Minecraft/Fabric в этой среде недоступны, поэтому
полную сборку надо проверить на Fedora.
