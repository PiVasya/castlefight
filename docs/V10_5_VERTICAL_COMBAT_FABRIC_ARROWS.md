# Castle Fight V10.5 — вертикальный бой и стрелы только в Fabric

## Требования автора

- Ближники сохраняют существующие горизонтальные дистанции. Допустимая
  разница высоты между ногами атакующего и целью: не больше 3 блоков.
- Дальники не стреляют сквозь блоки. Если цель перекрыта препятствием,
  освобождают её и продолжают движение по своему лайну. Если открытый
  прострел появляется снова, могут остановиться и атаковать.
- Старую серверную визуализацию стрел удалили **полностью**: никаких
  `SpawnEntityPacket`, `DestroyEntitiesPacket`, физических vanilla-стрел,
  а также fallback для игроков без клиентского мода.
- Визуальные стрелы рисует только клиент Fabric из одного серверного
  пакета `castlefight:shot_visual_v1` на каждый выстрел.
- Сервер по-прежнему решает, можно ли стрелять, существует ли цель,
  доступен ли прострел, когда применять урон и какой урон нанести.
  Клиент никогда не отправляет урон и не ведёт игровую симуляцию стрел.

## Протокол и старые клиенты

Клиент V10.5 отправляет короткое подтверждение совместимости по каналу
`castlefight:shot_hello_v1` при входе. Сервер отправляет кадр выстрела только
тем игрокам в нужном мире, которые подтвердили эту возможность и находятся
не дальше 96 блоков от стрелка. Подтверждение необходимо лишь для совместимости
с протоколом и **не** включает никакую прежнюю визуализацию.

Игрок с vanilla или прежним клиентским модом НЕ увидит стрелы Castle Fight.
Но бой и урон мобов остаются серверными и продолжают работать. Для показа
стрел нужны обновлённые сервер V10.5 и Fabric-мод V10.5 одновременно.

## Обновление на Fedora

Из Git-корня:

```bash
bash build.sh server
bash build.sh client
```

Готовый сервер: `dist/CastleFight` — переносимая папка с `start.sh`,
`core`, `maps`, `data`. Если готовый сервер уже вынесен из Git, после успешной
сборки обнови **только** его `core/` и `start.sh`, не трогая `maps/` и `data/`.
Готовый мод: `dist/client/castlefight-client.jar`; положи в `mods/` профиля
Minecraft 26.2 Fabric, удалив предыдущий JAR Castle Fight, чтобы не было двух
версий мода одновременно. Требуется Fabric API.

## Тесты

- `CFCombatHeightSelfTest`: численная проверка вертикального ограничения.
- `CFShotWireSelfTest`: длина и валидация пакета и handshake.
- `CFArrowMotionSelfTest`: вычисление срока жизни и положение визуальной стрелы.
- Автоматизированная проверка исходника: `CFClientShot.java` не содержит
  `SpawnEntityPacket` / `DestroyEntitiesPacket` / `EntityType.ARROW`.
- Игровая проверка: вертикально пересекающиеся лайны, сплошное перекрытие,
  открытый прострел, продолжение марша после потери цели, клиентские стрелы.

Полная компиляция на Java 25 и визуальный запуск Minecraft 26.2 должны быть
подтверждены на Fedora; наличие исходников и автономные тесты недостаточны.
