# Castle Fight Overlay — клиентский мод v0.1

**Minecraft Java 26.2 · Fabric · Java 25 · Fabric API**

## Что делает

- Клавиша **G** включает/выключает разметку непосредственно на клиенте.
- Строительные ковры всех 16 цветов показаны полупрозрачными зонами.
- Внешний контур каждой одноцветной зоны — чёткая двойная линия.
- Маршруты 1–4 показаны широкой цветной полосой с тёмной окантовкой.
- Данные **НЕ сканируются на клиенте**: сервер КФ присылает результат расчёта.
- Сервер отправляет разметку **один раз за подключение**, как только карта
  скомпилирована и игрок завершил вход в мир.
- Разметка целиком в **RAM**; никакого файла кеша, повторного запроса при G,
  сети при переключении или зависимости от Git/папки карт.
- После отключения от сервера память очищается. На следующем входе сервер
  снова отправит данные ОДИН раз.
- **V10.5:** показывает летящие стрелы Castle Fight без создания настоящих
  vanilla-сущностей стрел. Каждый полёт рисуется локально из одного сообщения
  сервера; боевая логика и урон остаются на Minestom.
- **Никакой старой визуализации нет.** Игроки без обновлённого Fabric-мода
  не видят стрел Castle Fight, но сами боевые попадания работают. Сервер
  посылает данные о выстреле только клиентам, подтвердившим поддержку.


## Сборка

Для исходников мода нужен **JDK 25**, **Gradle 9.5.1+** (рекомендован 9.7.1)
и доступ к интернету для скачивания Minecraft 26.2, Fabric Loom и Fabric API.

Открой терминал **в корне общего Git-репозитория**:

```bash
bash build.sh client
```

Скрипт использует Gradle из `PATH` или `client/gradlew`, если он добавлен.

Готовый Fabric JAR будет в `dist/client/castlefight-client.jar` (временные файлы Gradle остаются в `client/build/`).
Перенеси его в `.minecraft/mods/` профиля Minecraft **26.2 с Fabric**.
Также установи **Fabric API для 26.2**.

Мод **только клиентский**. На сервере не нужны Fabric и Gradle:
нужна совместимая сборка Minestom из `server/` этого Git-репозитория (сборка `bash build.sh server`).

## Проверка

1. Запусти обновлённый сервер КФ с подготовленной картой Map 3.0.
2. Подключись с Minecraft 26.2 с установленными Fabric, Fabric API и модом.
3. После получения разметки увидишь сообщение в чате: «Разметка ... получена».
4. Нажми **G**: появятся зоны строительства и полосы пути.
5. Нажми **G** повторно: исчезнут. Никаких пакетов отправлено не будет.

Клавишу можно изменить в «Настройки → Управление».

## Что НЕ делает

- Не сохраняет карту или геометрию на диск.
- Не изменяет блоки Minecraft, не ставит башни, не управляет матчем.
- Не читает/не вычисляет маршруты и строительные зоны самостоятельно.
- Не работает на Minecraft 1.21.x или на чистом vanilla-клиенте.

## Разметка и правило автора

**Цвет ковра = конкретная команда + конкретная дорожка.**
Два разных цвета НЕ объединяются в одну цельную зону, даже когда имеют
одинаковую пару `(команда, дорожка)`. Это сознательное правило КФ.

## Ограничения и проверка готовности

Обмен пакетами, сжатие, контрольная сумма, сегментация, сборка пакетов вне
порядка и расчёт цветных границ протестированы автономными Java-тестами.
Полная сборка Fabric 26.2 и визуальный игровой тест **ещё не подтверждены**
(в среде подготовки нет JDK25, Gradle и доступа к Maven/Fabric). Если
`bash build.sh client` выдаст ошибку, отправь лог: поправим именно API несовместимости.
